# KOA 진행 보고 — 클러스터 검사 → MCP 자동 연결 → 연결 확인

> 2026-10-05 · KOA v0.1.1 · 테스트 클러스터 `kind-lab` 에서 검증

## 한 줄 요약

KOA 에게 **"클러스터 확인하고 MCP 세팅해줘"** 한 마디만 하면, 클러스터를 검사하고 → 쓸 수 있는 관측 도구 5개를 자동으로 연결하고 → 실제로 조회되는지까지 확인한다. 질문 없이 **42초**에 끝났다. 클러스터는 아무것도 바꾸지 않는다.

## 먼저, 용어

| 용어 | 뜻 |
|---|---|
| KOA | 쿠버네티스 장애 원인을 찾아 주는 AI 에이전트. Hermes(AI 에이전트 프로그램) 위에서 돈다 |
| 클러스터 | 서비스들이 실제로 돌아가는 쿠버네티스 환경 |
| MCP | AI 가 외부 시스템(Prometheus, Grafana 등)을 조회할 수 있게 해 주는 연결 장치 |
| 읽기 전용 | 보기만 가능하고 바꾸기·지우기는 불가능한 권한 |
| kubeconfig | 클러스터 접속 정보 파일. KOA 는 읽기 전용 파일(`~/.kube/hermes-readonly.yaml`)만 쓴다 |

## KOA 가 하는 일

```
① 사전 점검        읽기 전용 계정인지 확인 (아니면 멈춤)
      ↓
② 클러스터 검사    어떤 도구가 있는지 찾음 → 보고서 작성
      ↓
③ 권한 확인        연결할 계정이 정말 읽기 전용인지 각 시스템에 물어봄 (쓰기 가능하면 연결 안 함)
      ↓
④ MCP 자동 연결    찾은 도구 중 접속 정보가 있는 것을 연결
      ↓
⑤ 연결 확인        도구마다 실제로 한 번 조회해 봄
      ↓
⑥ 결과 보고        표로 정리 + 못 붙인 것과 그 이유
```

## 결과 (kind-lab)

**클러스터**: Kubernetes v1.37, 노드 3대, 파드 65개, 관측 관련 구성요소 11개 발견.

**연결된 MCP**

| MCP | 무엇을 보나 | 권한 확인 | 실제 조회 결과 |
|---|---|---|---|
| kubernetes | 파드·이벤트·로그 | ✅ 읽기 전용 | 노드 3대 모두 Ready |
| prometheus | 지표(CPU, 재시작 수, 알림) | ✅ 읽기 전용 | 수집 대상 22개 모두 정상 |
| grafana | 대시보드·데이터소스 | ✅ 읽기 전용 (Viewer) | 데이터소스 2개 |
| argocd | 배포 상태·이력 | ✅ 읽기 전용 (쓰기 12종 모두 거부) | 앱 3개 모두 정상 |
| opensearch | 앱 로그 검색 | ⚠️ 주의 (아래 참고) | 상태 green |
| rabbitmq | 메시지 큐 | – | ❌ 연결 못 함 (아래 참고) |

**확인 방법**: 연결 직후 자동 조회 1회 + 앱 재시작 후 새 채팅에서 5개 MCP 모두 직접 조회해 같은 결과를 받았다. 연결 후에는 "지금 발화 중인 알림 알려줘" 같은 질문에 KOA 가 MCP 로 직접 답한다.

## 안전 장치

KOA 는 **클러스터를 절대 바꾸지 않는다.** 바꾸는 것은 KOA 자신의 설정(MCP 연결)뿐이다. 쓰기를 4겹으로 막는다.

| # | 장치 | 막는 것 |
|---|---|---|
| 1 | 읽기 전용 계정 | 클러스터·각 시스템이 쓰기 요청을 거부 |
| 2 | 연결 전 권한 확인 | 쓰기 가능한 계정이면 연결 자체를 안 함 |
| 3 | 조회 도구만 노출 | AI 에게 쓰기 도구가 아예 보이지 않음 (예: Grafana 62개 중 20개만) |
| 4 | MCP 서버 읽기 전용 모드 | 위가 다 뚫려도 서버가 쓰기를 거부 |

토큰·비밀번호는 `.env` 파일에만 두고 화면·대화·기록 어디에도 출력하지 않는다 (14개 파일 검사, 노출 0건).

## 새 장비 · 새 클러스터에서 쓰는 법

| 단계 | 누가 | 할 일 |
|---|---|---|
| 1 | 사용자 | `hermes profile install github.com/leejw1212/koa --alias` |
| 2 | 클러스터 관리자 | 읽기 전용 kubeconfig 생성 (`k8s/make-readonly-kubeconfig.sh`) |
| 3 | 사용자 | 각 시스템의 **읽기 전용** 토큰을 `~/.hermes/profiles/koa/.env` 에 입력 (Grafana Viewer, Argo CD readonly 등) |
| 4 | 사용자 | 데스크톱 앱에서 프로필 **koa** 선택 → "클러스터 확인하고 MCP 세팅해줘" |
| 5 | 사용자 | 앱 재시작 → 새 채팅에서 장애 분석 시작 |

규칙·작업 절차(스킬)는 설치할 때 함께 들어가므로 따로 가르칠 필요가 없다.
