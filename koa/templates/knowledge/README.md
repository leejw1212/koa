# 클러스터 지식 템플릿

`local/knowledge/<클러스터>/` 로 복사해서 채운다 (설치본 기준. 개발 체크아웃은 저장소 밖에 둔다 — 회사 내부 이름이 들어간다).
대화로 넣으면 KOA 가 같은 형식으로 쓴다. 설계: `docs/koa-analysis-inputs.md`.

| 파일 | 누가 | 내용 |
|---|---|---|
| `architecture.md` | 관리자, 자유 서술 | 전체 구조, HTTP·비동기 흐름 설명, 운영 관행, 주의할 점 |
| `flows.yaml` | KOA 가 정리, 관리자가 확인 | 구성요소 → k8s 워크로드, 흐름 hop, 정상 패턴. 분석 경로를 여기서 정한다 |
| `incidents/*.md` | 관리자 또는 분석 후 KOA 초안 | 과거 이슈 1건 = 파일 1개. 머리말의 signature 가 다음 분석의 1순위 확인 항목 |

모르는 칸은 비워 둔다. 틀린 값보다 빈 값이 낫다.
